# Art Inventory & Transaction Management System

Java-based art inventory and transaction management system with file persistence, validation, and automated testing.

## What it does
- Manages inventory for paintings, drawings, prints, and sculptures
- Creates, completes, and queries transactions (pending vs. completed)
- Calculates shipping-inclusive totals using art-type rules
- Persists inventory, customers, and transactions to local text files

## Tech
Java • Swing (UI) • File I/O (persistence) • JUnit 5 (unit + integration tests)

## Run
Open the project in your IDE and run the application entry point (GUI launcher in `src`).

## Tests
Run the JUnit test suite (includes unit + integration tests).
